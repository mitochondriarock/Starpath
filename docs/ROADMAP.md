# STARPATH — development roadmap

The priority is **transferable field skills**, not just collecting quiz answers. Each mechanic should have a validated model, explicit uncertainty, and a reason to practice it.

## 0.2 — Playable foundation (completed)
- [x] Four-stage Rocky Mountain nighttime navigation expedition
- [x] Time/location-responsive bright-star chart and observatory
- [x] Water-refraction demonstration
- [x] Uncertainty-first plant/fungus field guide decisions
- [x] Responsive mobile layout and offline standalone HTML

## 0.3 — Real sky, better learning loop
- [ ] Broader verified bright-star catalog, constellation overlays and Southern Cross lesson
- [ ] Horizon and field-of-view improvements; magnetic versus true north explanation
- [ ] Guided feedback tied to *causes* of navigational error
- [ ] Test astronomical positions against reference ephemerides on multiple dates/locations
- [ ] Field notebook with spaced-retrieval practice and an optional accessibility mode

## 0.4 — Navigation as a consequential adventure
- [ ] Terrain map with movement, hazards and changing visibility
- [ ] Dead reckoning, compass bearings, course correction and uncertainty propagation
- [ ] Weather and daylight choices with clear boundaries between game and reality
- [ ] Progression through multiple biomes and hemispheres

## 0.5 — Refraction lab expanded
- [ ] Adjustable observer height and angle, water depth and surface waves
- [ ] Compare the observed ray, back-projected apparent location and true target position
- [ ] Simulated tool trajectories with outcomes clearly framed as *game physics*
- [ ] Conservation, legal and ethical modules before any real-world fishing application

## 0.6 — Botany/mycology field school
- [ ] Curated regional species cases with provenance and look-alike comparison
- [ ] Teach habitat, morphology, gills/pores, spore evidence, seasons and uncertainty
- [ ] Focus on **non-consumption identification** and safe referral to local experts
- [ ] No edibility clearance from AI, photographs, or game scores

## 1.0 — Coherent survival-learning campaign
- [ ] Integrated night navigation, water safety, signaling, shelter and risk management
- [ ] Environmental adaptation, accessible difficulty and knowledge checks
- [ ] Human review of high-consequence content and documented educational validation

## Architecture principles

Keep simulation physics separable from rendering. Document model simplifications. Test astronomy and optics with reference cases. Make every module work without location permissions. Do not collect player data by default, and never frame a game outcome as authoritative wilderness or medical advice.
